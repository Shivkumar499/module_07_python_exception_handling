# Student Record Validation System

## About the Project

Student Record Validation System is a Python-based mini project that demonstrates exception handling and JSON file processing.

The project reads student records from a JSON file, validates the records, and handles errors that may occur during file processing.

## Features

- Read student records from a JSON file
- Validate student records
- Handle missing files
- Handle permission errors
- Handle invalid JSON data
- Store validation results
- Record import errors

## Technologies Used

- Python
- JSON
- Exception Handling
- File Handling
- Lists and Sets
